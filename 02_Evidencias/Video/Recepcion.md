# 📖 Descripción

Como parte del proceso de **Ingeniería de Requisitos**, se realizó una entrevista con el personal del **Área de Recepción**, utilizando la técnica de **entrevista estructurada** para recopilar información sobre las actividades desarrolladas, los procesos de atención al usuario, las necesidades existentes y los requerimientos necesarios para el desarrollo del sistema.

La evidencia audiovisual presentada en este repositorio constituye el respaldo documental del proceso de **levantamiento de requisitos**, proporcionando soporte para la identificación, análisis y validación de los requisitos funcionales y no funcionales que conforman la **Especificación de Requisitos de Software (ERS/SRS)** del proyecto **Sistema de Gestión Inteligente para un Centro Médico (SICM)**.
