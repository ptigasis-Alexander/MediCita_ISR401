# 📖 Descripción

Como parte del proceso de **Ingeniería de Requisitos**, se realizó una entrevista con el personal del **Área de Psicología**, utilizando la técnica de **entrevista estructurada** para recopilar información relacionada con el funcionamiento del área, los procesos desarrollados, las necesidades existentes y los requerimientos necesarios para el desarrollo del sistema.

Las evidencias audiovisuales presentadas en este repositorio constituyen el respaldo documental del proceso de **levantamiento de requisitos**, proporcionando soporte para la identificación, análisis y validación de los requisitos funcionales y no funcionales que conforman la **Especificación de Requisitos de Software (ERS/SRS)** del proyecto **Sistema de Gestión Inteligente para un Centro Médico (SICM)**.

# 🎓 Importancia Académica

> [!TIP]
>
> Las evidencias audiovisuales documentan la aplicación de la técnica de **entrevista estructurada** como método de **elicitación de requisitos**, conforme a las buenas prácticas establecidas por la norma **ISO/IEC/IEEE 29148:2018**.

Las grabaciones permiten:

- Verificar el origen de los requisitos documentados.
- Garantizar la trazabilidad de la información obtenida.
- Validar los procesos analizados durante la entrevista.
- Evidenciar la participación de los actores del dominio.
- Sustentar técnicamente la elaboración de la **Especificación de Requisitos de Software (ERS/SRS)**.
