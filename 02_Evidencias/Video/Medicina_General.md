# 📖 Descripción

Como parte del proceso de **Ingeniería de Requisitos**, se desarrolló una entrevista con el personal del **Área de Medicina General**, utilizando la técnica de **entrevista estructurada** para obtener información sobre el funcionamiento del área, sus procesos, necesidades, problemas y requerimientos.

Las evidencias audiovisuales presentadas en este repositorio constituyen el respaldo documental del proceso de **levantamiento de requisitos**, sirviendo como soporte para la identificación, análisis y validación de los requisitos funcionales y no funcionales definidos en la **Especificación de Requisitos de Software (ERS/SRS)** del proyecto **Sistema de Gestión Inteligente para un Centro Médico (SICM)**.
