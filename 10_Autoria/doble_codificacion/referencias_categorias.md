## ✅ Instrucciones para cada codificador

| # | Paso |
|---|---|
| 1 | Abre tu hoja (`hoja_CODIFICADOR_A.csv` o `hoja_CODIFICADOR_B.csv`) |
| 2 | Lee cada segmento **de forma independiente** — no consultes con el otro codificador mientras lo haces |
| 3 | En `codigo_asignado`, escribe el código (ej. `C01`) que mejor describe el segmento. Si aplica más de uno, sepáralos con coma (ej. `C01,C20`) |
| 4 | Escribe tu nombre en `nombre_del_codificador` |
| 5 | Guarda y avisa cuando ambos códigos estén listos, para calcular el Kappa |
