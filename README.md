## 📖 Resumen del dominio

**SICM (Sistema de Gestión Inteligente para un Centro Médico)** es el sistema que se está especificando y prototipando en este repositorio como parte del curso de Ingeniería de Requisitos. Su dominio es la **gestión operativa de un centro médico privado de mediana escala**, con las siguientes áreas identificadas mediante entrevistas de elicitación: Medicina General, Terapia Física, Nutrición, Odontología/Coordinación, Enfermería, Psicología, Recepción/Recaudación, y la perspectiva del paciente.

El sistema busca resolver problemas actuales como el agendamiento manual en hojas de cálculo, la fragmentación de la historia clínica entre áreas, la comunicación deficiente entre departamentos para derivaciones, y el control manual de inventario de medicamentos — todos identificados directamente en el proceso de codificación temática de las entrevistas (ver [`02_Evidencias/Codificacion_Tematica/`](02_Evidencias/Codificacion_Tematica/)).

## 🔬 Cómo reproducir el análisis experimental

El análisis experimental vive en [`06_Experimento/`](06_Experimento/), organizado así:

```
06_Experimento/
├── protocolo.pdf              ← diseño del experimento paso a paso
├── osf_registration.pdf       ← pre-registro (hipótesis fijadas antes de correr el experimento)
├── instrumentos/               ← instrumentos de medición/evaluación usados
├── prompts_llm/                 ← prompts exactos usados con el/los modelo(s) de lenguaje
├── resultados/                 ← salidas crudas del experimento
└── scripts_analisis/           ← scripts que procesan resultados/ y generan las métricas finales
```

Pasos para reproducir:

1. Clona el repositorio:
   ```bash
   git clone https://github.com/ptigasis-Alexander/MediCita_ISR401.git
   cd MediCita_ISR401/06_Experimento
   ```
2. Lee `protocolo.pdf` para entender el diseño experimental y las variables medidas.
3. Revisa `prompts_llm/` para ver los prompts exactos usados (necesarios para replicar las corridas con el LLM).
4. Corre los scripts de `scripts_analisis/` sobre los datos de `resultados/` para regenerar las métricas y gráficas reportadas en el manuscrito.

> [!WARNING]
> Al momento de escribir este README, `06_Experimento/` todavía contiene solo la estructura de carpetas (placeholders), sin `protocolo.pdf`, `osf_registration.pdf` ni scripts reales. Esta sección debe actualizarse con los comandos exactos (ej. `python scripts_analisis/analizar.py`) una vez el contenido esté subido.

## 🤖 Guía rápida para revisión (humana o por IA)

Si vas a evaluar este repositorio, sigue este orden:

1. Lee este `README.md` completo (estás aquí).
2. Abre el ERS/SRS en [`01_ERS/`](01_ERS/) para entender el alcance funcional y no funcional.
3. Revisa la evidencia de elicitación en [`02_Evidencias/`](02_Evidencias/) — cada subcarpeta tiene su propia guía de verificación (`Guia_Verificacion_*.md`) con pasos reproducibles y un checklist de aprobación.
4. Prueba el MVP en vivo: [ptigasis-alexander.github.io/MediCita_ISR401/05_MVP/](https://ptigasis-alexander.github.io/MediCita_ISR401/05_MVP/)
5. Verifica la trazabilidad entre requisitos, historias de usuario y evidencia en [`04_Trazabilidad/`](04_Trazabilidad/).
6. Revisa el cumplimiento ético en [`08_Etica/`](08_Etica/).
