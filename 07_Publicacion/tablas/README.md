# Tablas de la publicación

Esta carpeta contiene las tablas generadas a partir del análisis reproducible de MediCita.

| Archivo | Descripción |
|---|---|
| `cobertura_must.csv` | Resultados de cobertura técnica de los requisitos Must. |
| `resumen_validacion.csv` | Resumen cuantitativo de la validación walkthrough. |

Las tablas se generan mediante la cadena de análisis y sirven como fuente para el manuscrito final.
