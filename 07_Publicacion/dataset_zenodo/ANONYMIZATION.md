# ANONYMIZATION

El conjunto público contiene únicamente datos derivados y seudonimizados.

## Transformaciones aplicadas
- Se utilizan códigos de participante/sesión cuando aparecen en los datos analíticos.
- No se publican nombres, cédulas, correos, teléfonos, firmas, rostros, voces ni archivos audiovisuales.
- No se incluyen consentimientos firmados ni la tabla de correspondencia entre códigos e identidades.
- Las transcripciones completas y la evidencia multimedia permanecen fuera de este conjunto público cuando puedan permitir identificación.
- Los comentarios se mantienen solo en la medida en que no contienen identificadores directos detectados en la revisión del paquete.

## Riesgo residual
La seudonimización no equivale a anonimización absoluta. Por ello, el depósito abierto se limita a tablas derivadas necesarias para reproducir los resultados descriptivos y técnicos.

## Estado
Este directorio está preparado para depósito, pero no se declara DOI de Zenodo hasta que el depósito exista realmente.
